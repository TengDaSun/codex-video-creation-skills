# 素材整理

先读取 [文件规则](../video-workflow/references/files.md)。本技能依赖随包安装的 video-workflow 通用参考。

1. 核对指定素材目录和目标目录，限定在本次范围内；不默认扫描整个磁盘或连接手机。
2. 运行 `python scripts/organize.py "素材目录" "新的索引目录"`，生成素材索引及 SHA-256 重复组。源文件只读，脚本拒绝覆盖已有索引。
3. 用户要求实际分类时加 `--copy`，在索引目录内生成按日期的分类副本，不移动、不删除原件。相同字节只复制一份，但索引保留每个来源。输出目录不能在源目录内。
4. 拍摄时间优先使用可用 exiftool 的 DateTimeOriginal/CreateDate；否则 ffprobe 创建时间，均记录来源且不推断拍摄时区。读取不到归入日期未知，不拿修改时间冒充拍摄日期。EXIF 工具可选，缺失不阻止索引。
5. 视觉上相似不等于重复。按活动/内容归类需实际看缩略图，脚本只按日期和文件类型整理。查看失败、损坏、权限问题留在索引 errors，说明缺项。
6. 手机相册先让用户导出到本地文件夹；保留 Live Photo 配对和编辑后版本，不附带原作者的设备连接脚本。照片 HEIC/HDR 是否可供剪辑需单独验证。

交付索引位置、总量、重复组、无法读取项及实际复制数量。建议删除仅列候选，删除另依当前任务授权。
