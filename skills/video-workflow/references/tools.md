# 按素材选择制作工具

优先沿用最后认可工程及已验证脚本。只做局部修改时，不为换工具重新剪辑。新任务先查当前环境的能力，按素材、目标效果、已有工程、耗时与费用选择；普通选型由 Codex 判断，只有影响方向或未授权费用时才问用户。

| 当前可用工具 | 适合的工作 | 使用条件 |
|---|---|---|
| FFmpeg 与现有脚本 | 切段、拼接、尺寸适配、混音、转码与检查 | 当前脚本能稳定完成需求时直接复用；复杂时间线编辑可采用已连接编辑器。 |
| ChatCut | 实拍、访谈、作品录屏的时间线剪辑、字幕与声画编排 | 用户指定或任务已建立 ChatCut 编辑上下文，且连接、素材与导出能力可用；不因本表出现名称就访问其工具。 |
| 开拍等模板工具 | 字幕、花字及模板包装 | 用户可用账号、权益与导出路径均已核实；需要额外收费先说明。 |
| Remotion | 已有 React 工程、精确时序、系列组件或数据驱动动画 | 实际环境有依赖和对应技能，效果确实受益时使用。 |
| HyperFrames | HTML/CSS 图文动效、信息卡、章节提示与合成 | 实际环境有依赖和对应技能，已有网页样式或工程可复用时使用。 |

以上为选型线索，不要求安装或用齐这些工具；使用具体工具前读取其当前技能和约束。缺少某个产品仍可选择已有可用路径。额外订阅、付费生成不由安装本 Skill 自动授权。

一个主工程负责最终装配和导出，一个环节统一处理字幕、标题和花字。交给模板工具加字时，上游输出无文字底片及校正文稿；已有混音不再叠一套模板音乐。跨工具交接检查尺寸、时长、帧率、像素比例、颜色、音轨与字幕，避免重复转码。

首次采用链路时先做代表性短样，核实实际导出、文字、声音及颜色，再继续整片。重复故障先查原因，记录已试范围，回退能完成需求的稳定路径；不要把待交付视频拖成无期限工具研究。

在本条清单 `production_plan` 记录选择依据、工具职责、主工程、文字负责人、费用依据、回退路径及已验证范围。具体工具名和价格来自本机与当前账户，不能从分享包推定安装、免费或已接通。
