# Codex 视频创作技能包

**designed by AI for Kid工作室**

一套供 Codex 使用的视频创作技能，帮助你整理素材、剪辑视频、制作封面与文案，并在获得授权后按实际平台条件发布。

## 包含的技能

| 技能 | 用途 |
| --- | --- |
| `video-workflow` | 总入口，按需求串联各个环节 |
| `video-organize` | 素材索引、查重及可选分类副本 |
| `video-edit` | 基础视频剪接与导出检查 |
| `video-package` | 制作封面、文案和发布包 |
| `video-publish` | 核对授权、账号与版本后执行发布流程 |

## 安装

需要 Python 3.10 或更高版本。下载或克隆仓库后，在仓库目录运行：

```bash
python3 install.py --dest ~/.codex/skills --check
python3 install.py --dest ~/.codex/skills
python3 ~/.codex/skills/video-workflow/scripts/doctor.py
```

安装器遇到同名技能会停止，不会覆盖已有文件。默认安装目录是 `~/.agents/skills`；上面命令明确指定 Codex 用户技能目录。安装后开始新对话，如未出现请重启 Codex。

基础视频剪辑需要 FFmpeg 和 ffprobe。字幕转写、配音、生成图片和平台发布需要各自可用的工具或服务，具体以实际环境为准。

## 开始使用

将素材放到本机文件夹，然后告诉 Codex：

> 使用 $video-workflow。素材在“素材文件夹路径”，帮我制作一条约一分钟的竖屏视频。先看素材、找出看点，保留原件；成片、封面和文案一起给我看，先不发布。

第一次使用可参照 [示例练习](示例练习/练习说明.md)。更多说明见 [先看这里](先看这里.md)，实际验证范围见 [验证说明](验证说明.md)。
