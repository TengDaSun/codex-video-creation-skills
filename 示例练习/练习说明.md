# 第一次练习

这里有两个合成的竖屏测试视频、一张 sRGB 测试图片以及一个字节相同的视频副本。合成声音是测试音，不是配乐或人声。素材可以用于本技能包的练习和再分发，不含真实人物。

目标：识别 4 个素材、1 个重复组；只复制 3 个不同素材；按照时间线装配约 6 秒 MP4；交付封面、文案和清单，全程不联网发布。

让 Codex 在新的练习目录复制“素材”及“时间线.json”，不要覆盖本包。实际命令中的技能脚本要改成安装后的路径：

1. `python video-organize/scripts/organize.py "练习目录/素材" "练习目录/素材索引" --copy`
2. `python video-edit/scripts/render_sequence.py "练习目录/时间线.json" "练习目录/成片.mp4"`
3. `python video-workflow/scripts/check_media.py "练习目录/成片.mp4" --width 360 --height 640 --duration 6`
4. 使用 $video-package 选实际测试画面制作封面，写清“流程练习”，不编造旅行、采访或真人经历。复制空白发布清单，只记录已完成项，授权保留 false。
5. 查验原素材指纹没变，成片能播放、两个视频段有测试音、中间照片段无声，未产生平台发布记录。

所有命令由 Codex 使用实际 Python 启动方式执行，不要求同学手改脚本。参考结果里的视频是基础装配对照，封面是提取的测试画面；它们只证明基础工具路径，不代表正式封面设计或完整视觉、听感验收。自己的素材建议用 1080×1920 或已有目标画幅，本练习 360×640 为了快速下载和渲染。

完成练习后再用自己的一组素材试做。没有真实看听、手机检查或平台回执时，清单对应项保持未完成。
